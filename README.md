💰 Expense Tracker

Expense Tracker is a Flutter-based mobile application designed to demonstrate a simple and practical approach to managing personal expenses. The app provides a clean, responsive, and device-friendly interface where users can record and review their daily spending.

📌 Project Overview

The application focuses on implementing core expense-management functionality while maintaining a simple and intuitive user experience. Users can add expenses by entering details such as title, amount, and date, and view their recorded expenses in an organized list.

The project demonstrates practical Flutter development concepts including responsive UI design, form handling, reusable widgets, state management, and user interaction.

✨ Key Features

* ➕ Add new expenses
* 💵 Enter expense title and amount
* 📅 Select expense date
* 📋 View recorded expenses
* 📱 Responsive UI for different screen sizes
* 🧩 Reusable Flutter widgets
* 🎨 Clean and minimal interface
* ⚡ Lightweight and smooth user experience

🎯 Project Goals

* Build a practical expense-management application using Flutter.
* Practice creating responsive and device-friendly mobile interfaces.
* Implement forms and handle user input effectively.
* Work with dates and dynamically display expense information.
* Improve understanding of Flutter widgets and state management.
* Follow a clean and maintainable project structure.
* Create a portfolio-ready application that demonstrates real-world mobile development concepts.

🛠️ Tech Stack

Flutter • Dart • Material Design

▶️ Run the Project

Clone the repository and navigate to the project directory:

git clone <repository-url>
cd expense_tracker

Install the project dependencies:

flutter pub get

Check connected devices:

flutter devices

Run the application:

flutter run

For a specific platform, you can use:

flutter run -d android

or:

flutter run -d chrome
